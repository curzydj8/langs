## 写作约定

- 每卷独立成文：`volN-*.md`，版本号随修订递增（V1.0 → V1.1）。
- 每卷末尾必须有「MVP 子集」一节：明确本卷内容中第一批要实现的部分。
- 数值（产量/消耗/成本）统一收敛到卷二，建筑卷只引用资源名，不许自创资源。
- 与实现交替推进：写一卷、实现一包，不许出现"写完十卷再开工"。
