# 💻 语言图鉴 · 计算机语言合集

一个收录 **144 种计算机语言**的静态网站：从 1949 年的汇编语言到 2023 年的 Mojo，
涵盖编程语言、标记语言、样式语言、数据格式、查询语言与硬件描述语言。

## 功能

- 🔍 实时搜索（按名称、作者、关键词、特性、关键字）
- 🏷️ 按类型 / 编程范式 / 年代筛选
- 📊 顶部数据统计（收录数、年份跨度、范式数）
- 📇 点击卡片查看详情：详细介绍、核心特性、核心关键字解析（共 576 条特性、1763 条关键字解析）、代码示例
- 🎲 随机一种语言逛逛
- 📱 深色主题 + 响应式，手机电脑都能看

## 部署到 GitHub Pages（3 步上线）

1. 在 GitHub 新建一个仓库（比如命名为 `langs`，或用 `你的用户名.github.io` 作为个人主页仓库）。
2. 把 `index.html`（和 `README.md`）上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，
   分支选 `main`、目录选 `/ (root)`，点 **Save**。

等待约一分钟，访问以下地址即可看到网站：

- 仓库名为 `你的用户名.github.io` → `https://你的用户名.github.io/`
- 其他仓库名 → `https://你的用户名.github.io/仓库名/`

## 本地预览

用浏览器直接双击打开 `index.html` 即可预览，无需任何构建步骤。
